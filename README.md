# HPGeochemistry
Standalone GUI for PHREEQC from HPx Framework


Download and unzip.
Place the folder HPGeochemistry where you want to have the HPGeochemistry.

If you install HPGeochemistry for the first time, copy the files from "Settings" to "HPGeochemistry/Settings".

If you update HPGeochemistry, you will need to overwrite the folders "Bin" and "Data" in your HPGeochemistry folder.

Do not overwrite the files in "HPGeochemistry/Settings", otherwise you will delete information on your own settings and project information.
